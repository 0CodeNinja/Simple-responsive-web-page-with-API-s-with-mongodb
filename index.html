The Four Pillars

CRUD → HTTP → MongoDB

Every database operation maps to an HTTP method and a Mongoose query.

🌱
CREATE

POST → INSERT

User.save() — Adds a new document to MongoDB collection permanently.

new User({...}).save()
🔍
READ

GET → SELECT

User.find() — Retrieves documents from MongoDB. Supports filter, sort, pagination.

User.find(filter).sort()
✏️
UPDATE

PUT → UPDATE

findByIdAndUpdate() — Modifies an existing document. runValidators ensures schema rules.

findByIdAndUpdate(id,data)
🗑️
DELETE

DELETE → REMOVE

findByIdAndDelete() — Permanently removes a document from the collection.

findByIdAndDelete(id)

Blueprint

Database Schema Design

Mongoose schemas enforce structure, types, and constraints — the database's immune system.

📋 User Schema

name: {
  type: String,
  required: true, // NOT NULL
  minlength: 2,
  maxlength: 50
},
email: {
  type: String,
  unique: true, // UNIQUE
  match: /email regex/
},
role: {
  enum: ['admin','editor','viewer'] // CHECK
},
timestamps: true // auto createdAt/updatedAt

📨 Contact Schema

name: {
  type: String,
  required: true
},
email: {
  type: String,
  required: true
},
message: {
  minlength: 10,
  maxlength: 1000
},
isRead: { type: Boolean, default: false },
timestamps: true
